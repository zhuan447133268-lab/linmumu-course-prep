# 金样摘录 —— 01 设计 / 03 讲稿 / 04 测验的"合格线"长这样

> 这是实测通过的产出摘录。生成新课时，**质量不许低于这个标准**。
> 判断方法：把你的产出和这里逐类对比——不像就返工。
> 注：本文件管**内容**标准，不管输出格式——03/04 自 v1.2 起以 docx 直出（版式由 scripts/docx_lib.py 固化），金样中的 markdown 摘录仅示意内容写法。

## 01_这一节的设计.md —— 结构骨架（全链之源，塌了后面全塌）

理工讲授课按这个骨架写 01（对应课件 15-18 页）：

```
导入（用真实问题或认知冲突 hook，5-10 分钟）
→ 概念建构（关键概念逐个落地，每个配一种可视化）
→ 板书级手算示例（数字凑得手算可行）
→ 易错对比（"学生最常犯的错"正面攻，接 05 交互演示）
→ 课堂快测（2-3 题，检验目标达成）
→ 总结 + 下节伏笔
```

工具/培训类课可换成「看成品 → 跟做 → 带走」三段（见下面文科金样），但三条不变：目标可观察、每条目标有落点、时间加总=时长。

01 里还应有**思政融入点（可选字段）**：只写本主题**天然携带**的价值引领点（如工科的工匠精神与工程规范、信息技术课的数据安全意识）。没有就不写，**禁止硬凑**——硬凑的思政比没有更伤教案。

## 01_这一节的设计.md —— 教学目标的写法

❌ 不合格：`使学生掌握正运动学的基本概念和计算方法`
✅ 合格：

```
学生下课能：
1. 给定 θ₁、θ₂，不查资料手算出末端坐标（误差 < 5 mm）
2. 指出"θ₂ 相对谁"这句话里的坑，并解释为什么末端会差 253.6 mm
```

标准：**动词必须是可观察的行为**（手算/指出/画出/判断），数字可验收。
"掌握 / 了解 / 理解 / 熟悉"出现即为不合格。

**文科金样（工具/培训类课，同样合格）**——注意它不用公式数字，用"可检验的动作"替代：

```
培训结束后，教师能够：
1. 独立说出工作台四块拼图分别解决什么问题，并从自己的工作里挑出 1–2 块最需要的；
2. 用一句大白话向 AI 生成一个"能保存、双击即开"的最小版个人工作台，不写代码、不装软件；
3. 守住安全底线：在需求里主动加入"只能看、不能改我的原文件"和"内容存我电脑本地"两句防护语。
```

文科课的"学生最常犯的错"照样要具体到行为：不是"老师不会用 AI"，而是"**生成时漏说'内容存在我自己的电脑上'——一刷新就清空，然后弃用**"。

## 03_讲稿（docx 直出）—— 语气和结构的合格线

- 口语，短句，像老师平时说话。不许出现"综上所述""值得注意的是"这类书面腔
- 每 8-12 分钟一个【提问】或【停顿】——【提问】必须是具体的问题原文，不是"提问互动"四个字
- 关键概念用"错误理解 vs 正确理解"的对比讲，并给出**具体数字的代价**（差 253.6 mm，不是"误差很大"；**数字必须先用脚本算出来再写**，见 SKILL 铁律 9）
- 例题数字要凑得让手算可行，**不许出 cos 37° 这种查表都难的数**（除非本节就是教查表）
- 每段标时间（如 `## 10-25′`），全篇加起来 = 本节课时长

合格样例：

```
现在是今天最要命的地方。θ₁ 是大臂相对基座水平线抬起来的角度，这个大家好理解。
那 θ₂ 呢？
【提问：θ₂ 是谁和谁的夹角？】
注意听——θ₂ 是连杆 1 和连杆 2 之间的夹角，不是连杆 2 相对水平线的角度。
这两个理解差多少？如果 θ₁ = 60°、θ₂ = 30°，按正确的理解，连杆 2 相对水平线
就是 90°，竖着朝上。按错误的理解，只有 30°，几乎是平的。末端位置能差出去
整整三百毫米，工件直接抓空。
```

## 04_测验（docx 直出）—— 题目的合格线

每题必须三件套：答案 / 一句解析 / 对应哪条教学目标。干扰项必须是**真实 misconception**，不能是凑数的：

✅ 合格样例：

```
Q3（单选）θ₁=60°、θ₂=30°，L₁=400、L₂=300。连杆 2 相对水平线的角度是多少？
A. 30°   B. 60°   C. 90°   D. 120°
答案：C。θ₂ 是两杆夹角，末端方向角 = θ₁+θ₂ = 90°。
对应目标 2。干扰项 A 就是"θ₂ 相对水平线"这个典型错误——选 A 的学生正是没分清基准。
```

标准：一个干扰项对应一个学生在真实作业里会犯的错。凑数的干扰项（明显离谱的）不算合格。

**简答题必须有采分点**，不许一段笼统参考答案：

```
Q15（简答）为什么检测准确率 99% 的病，阳性结果仍然可能大概率没病？
采分点（每个 1 分，答出 2 个即满分）：
① 基础发病率远低于漏检率——健康人基数太大（先验低）
② 99% 指的是"有病的人里测出阳性的比例"，不是"阳性的人里有病的比例"（搞反了条件概率方向）
```

**文科金样（讲稿开场）**——口语、具体、有画面，hook 是让老师"数自己的待办散在几处"：

```
各位老师，先不讲课。我问个事：您现在手头的待办，散在几个地方？
【停 3 秒，让大家自己数】
微信一个、浏览器收藏一个、便签一个，还有脑子里那个最不靠谱的。
李老师也是这样——早自习家长群三条留言，中午要交教研材料，下午想查上周
收藏的两篇论文，晚上还得备课。她的问题不是不努力，是东西太散。
```

## 05_交互演示.html —— 唯一硬标准

围绕"学生最常犯的错"做**正确/错误两种状态的实时对比**：勾选"按错误理解算"，画面直接画出错误结果（灰色虚线）+ 显示差距数字。底部一句话"现在发生了什么"。单文件、双击能开、无英文菜单。

## 06_挑刺报告 —— 三个角色各 3 条，且必须真的挑出来

学困生只许说认知断层（跳步/术语没解释/例子太远），**不许提排版**；
同行只挑硬伤（过时说法/不严谨/更主流讲法）；
督导只对照教学目标（考核对不对齐/重难点有没有时间/目标落空）。
挑不出 3 条就少写，**不许凑数**——凑数的意见会浪费老师的时间去判断。
